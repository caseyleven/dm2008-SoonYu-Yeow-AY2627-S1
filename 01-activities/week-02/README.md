### This Week

<!-- A short, informal summary of what you explored across the week's activities. What did you make? What clicked? What didn't?
     A few sentences is all you need — write it like a journal entry, not a report. -->

For activity 2a, I made use of the guided activity to create 3 visual modes that created a trail and switched between different sizes and colours using keys '1', '2', and '3'. As I have mentioned before, I'm obseessed with trails. This time, I added strokes to the ellipse because the pattern left behind by the trail looked interesting. However, the trails left behind did affect the colour of the background. I was informed that it was a very common phenomenon on p5js.

For activity 2b, I was inspired by how audio waveforms look like, and so I implemented a mouseIsPressed function so that whenever the mouse was pressed, the circles would randomly stretch at different values and resemble a moving audio waveform.
